# LX Music 全量能力对标矩阵

> 目标：对齐公开、面向用户的能力与任务路径，按 Web 安全/浏览器边界和 Music Holo 的产品定位做适配优化；不逐像素复制界面，不复制参考项目代码、标识或未授权素材。
>
> 参考基线：`lyswhut/lx-music-desktop` v2.12.6（2026-09-19 发布）及 `lyswhut/lx-music-doc` 桌面版公开文档；本轮仅静态阅读源码/文档目录与界面实现，没有执行第三方脚本。LX README 指出桌面/移动的设置、快捷键、歌单管理和下载能力；文档还单列源脚本协议、歌单与列表、多选、快捷键、本地音乐、数据同步、歌词、开放 API、启动参数等。

## 产品能力矩阵

| 能力域 | LX Music 公开能力 | Music Holo 当前对照 | 判定与处理 |
| --- | --- | --- | --- |
| 搜索与发现 | 多来源搜索、排行榜/歌单、歌曲快速换源 | 有曲库统一搜索（歌曲/歌手/公开歌单/原文、译文与罗马音歌词）、排行榜、每日推荐、专辑聚合、相似歌曲电台；自定义源只负责按曲目解析 | **已有且体验方向不同**。LX 协议没有通用源侧搜索动作，Music Holo 不伪造该协议能力，不把自定义源搜索混进全局结果。 |
| 播放与队列 | 顺序/随机等播放模式、临时“稍后播放”、列表播放、队列历史/整理、快捷控制 | 已有顺序/循环/单曲循环/随机、播放全部、持久队列、睡眠定时、Media Session、键盘控制；全站歌曲行支持“下一首播放”，队列支持手动上/下移并保存曲库队列顺序 | **阶段 1 已实现并验收**。用户指定下一首优先消费一次；重复选择移动队列项而不重复加入，排序时保持当前曲目。生产构建浏览器旅程 CI run 37903076251 通过；未新增后端/API。 |
| 歌单与列表操作 | 我的列表、来源歌单、整单播放、稍后播放、多选、拖动排序、导入/导出与文本/CSV 备份 | 有账号歌单 CRUD、批量增删曲目、整单播放/加队列、公开分享、短评审核；阶段 2 已提供账号歌单 JSON 备份/恢复预览；歌曲库支持跨页勾选后批量加入队列或自己的歌单；歌单详情可由创建者上移或下移一首歌曲并保存 | **阶段 2 已实现并验收**。仅导出当前账号拥有的歌单；白名单字段与大小/版本校验；导入预览、曲目匹配/歧义选择、缺失跳过；只新建副本、同名改名，默认私密、公开需逐项明确选择。凭据、歌词、音频 URL 和脚本均不导入。导出后由用户点击真实链接保存，避免异步请求后的程序化下载被浏览器丢弃。跨页多选只在歌曲库开启，搜索、排行榜和管理后台不改。歌单排序只做一位上移/下移，不做整页拖拽，也不改播放队列已有排序；只有创建者能改。阶段 2 备份验收见 [CI run 37910475171](https://github.com/tough723/music-holo/actions/runs/37910475171)；歌单排序验收见 [CI run 37921782620](https://github.com/tough723/music-holo/actions/runs/37921782620)。 |
| 本地音乐 | 本地歌曲列表、文件元数据/标签支持、添加到本机列表 | 可多选本地音频临时播放；支持浏览器的浏览器可在用户点“记住本地文件”后把文件句柄放进 IndexedDB。刷新后只保留句柄名单，不自动塞回播放队列，需点“恢复已记住的本地音乐”并再次得到读取权限 | **网页端已实现授权句柄**。不扫描磁盘、不上传、不写服务端历史，也不读取标签库。不支持 File System Access 的浏览器仍使用一次性文件选择。 |
| 下载与离线 | 有下载任务队列、暂停/继续、质量/文件名/歌词标签等选项 | 在线播放仍使用原音频 URL。用户可把本站 `/audio` 演示文件保存到本机 IndexedDB，列出并删除；只在该地址加载失败时回退一次 | **不照搬下载器**。不抓取、缓存或导出未授权音频，不使用 service worker，不缓存外链、Blob、自定义源或上传目录。 |
| 歌词与播放器展示 | LRC、译文/罗马音、桌面歌词浮窗与多项歌词外观设置 | 原文/译文/罗马音均为独立 LRC。罗马音默认隐藏，播放器可切换；管理端可导入。搜索可按罗马音匹配，但列表和搜索不返回歌词正文 | **网页端已实现导入式罗马音**。不抓取未授权歌词，不做逐字歌词协议，也不把浏览器模拟成桌面置顶窗。 |
| 自定义源 | 用户管理源脚本；源可声明平台/音质并按协议解析音频/歌词/封面 | 有本机源库、导入/筛选/排序/备份、隔离 Worker 检测、用户逐次选源/音质并解析曲库歌曲；HTTPS/CORS、会话域名授权、匿名媒体加载 | **Web 安全适配版已覆盖关键链路**。保持隔离、不携带 Cookie/登录令牌；不绕过 CORS、不加通用代理；源搜索不属于公开通用协议动作。 |
| 同步与备份 | 桌面/移动数据同步服务；分项或全量备份/导入，另有文本/CSV 歌单导出 | 账号服务端保存收藏、歌单、播放历史/列表；浏览器有设置和自定义源的独立本机备份；阶段 2 已为账号歌单提供版本化 JSON 便携备份 | **歌单迁移路径已实现并验收**。备份只含歌单描述和曲库引用，不含账号秘密或媒体内容；其他账号数据不随本批备份。 |
| 个性化控制 | “不喜欢的歌曲/歌手”规则，切歌时自动跳过，可手动播放 | 账号隔离的歌曲 ID / 歌手 ID 规则；自动下一首、每日推荐、相似电台跳过；搜索、排行榜、管理后台和显式点播仍可见 | **阶段 3 已实现**。不是 LX 的本机歌名/歌手名精确匹配，也不做通配符或下载过滤。规则可撤销，不删除曲库；匿名不写他人数据。 |
| 设置与搜索偏好 | 音源、网络代理、音频设备、播放/歌词、列表、下载、搜索、快捷键、同步、备份等设置 | 有主题/动效/玻璃、播放模式/音量、搜索隐私、本机备份、账号资料与安全、自定义源设置 | **功能域已覆盖主要 Web 需求**。代理、系统音频设备和下载路径属于桌面/浏览器受限项，不为了形式对齐添加脆弱开关。 |
| 桌面/系统集成 | 全局快捷键、托盘、开机启动、始终置顶的独立桌面歌词窗、桌面开放 HTTP API、Scheme 启动参数 | 浏览器内键盘操作、Media Session 系统媒体控件、响应式窄屏播放器 | **不做 Electron 伪实现**。改用浏览器安全能力；宿主全局输入、托盘、任意本机 HTTP 控制面不进入 Web 版本。 |
| 社交/协作 | LX 核心不是实时协作社区 | 有歌曲/公开歌单短评、举报审核、公开歌单分享；没有协作编辑/同步听 | **当前已有 MVP**。协作歌单/一起听需要真实需求、内容治理与实时服务验算，不列入阶段 1。 |

## 分阶段实现顺序

排序依据是“用户任务覆盖 × 实现/维护负担 × 版权与安全风险”的相对判断，不是增长预测。当前没有真实用户使用基线，不承诺转化或留存提升；后续用真实测试与反馈重新排序。

| 顺序 | 工作包 | 优先级 / 规模 | 验收边界 |
| --- | --- | --- | --- |
| **阶段 1（本轮，已验收）** | 播放队列“下一首播放”与手动排序 | 高优先级，前端小改动；无需 SQL、服务端接口或第三方服务 | 在歌曲列表可把曲目排到正在播放曲目之后；重复选择移动已入队曲目而不是制造重复；队列上/下移后播放中的曲目保持不变；刷新后合法曲库队列顺序仍保存；本地 Blob/自定义源签名 URL 仍不进入持久化队列。Store 测试通过，生产构建 Playwright 于 [CI run 37903076251](https://github.com/tough723/music-holo/actions/runs/37903076251) 通过。 |
| **阶段 2（本批，已验收）** | 当前账号歌单 JSON 备份/恢复；跨页多选当时延期 | 中优先级；沿用现有歌单/曲库 API，新增专用前后端服务、DTO/VO、校验和测试；不加表；本轮未记录实际工时，不能据此声称具体人日 | 登录账号只能导出自己的歌单；2 MB/版本/白名单字段与数量校验；导入先预览，重名自动改名且只新建；默认私密，只有用户逐项勾选才公开；缺失歌曲显示并跳过，多个候选需人工选择；凭据、歌词、音频 URL、脚本不导入。后端验证、API smoke 与 20 项生产构建 Playwright 已于 [CI run 37910475171](https://github.com/tough723/music-holo/actions/runs/37910475171) 通过。 |
| **阶段 3（本轮，已验收）** | “不喜欢”歌曲/歌手规则 | 中优先级；新增账号规则表、API、推荐过滤与播放器跳过 | 歌曲和歌手都可屏蔽；账号隔离；可撤销；自动下一首、每日推荐、相似电台跳过；用户指定的下一首和显式点播不跳过；搜索、排行榜、管理后台不隐藏；匿名不写入。不做通配符和下载过滤。后端验证、Compose smoke 与 21 项生产构建 Playwright 已于 [CI run 37918054898](https://github.com/tough723/music-holo/actions/runs/37918054898) 通过。 |
| **跨页多选（阶段 2 延期项，本轮已验收）** | 歌曲库跨页勾选，批量加入队列或自己的歌单 | 前端选择状态；沿用现有队列与歌单加歌接口；不加表 | 翻页、返回上一页后选择仍在；本页全选不影响其他页；加入队列在浏览器播放列表去重；加入歌单只列出当前账号的歌单。搜索、排行榜和管理后台不提供这组勾选。生产构建 Playwright 已于 [CI run 37919336085](https://github.com/tough723/music-holo/actions/runs/37919336085) 通过。 | 
| **歌单曲目排序（本轮，已验收）** | 歌单详情上移/下移一位并保存 | 中优先级；新增所有者专用接口，不加表；不做整页拖拽 | 只有创建者能改，管理员不能改别人的歌单；已经在首尾时再移动不改变顺序；歌曲不在歌单返回 400；交换后把顺序重写成连续序号再保存。不改播放队列已有的上移/下移。后端验证、Compose smoke 与 23 项生产构建 Playwright 已于 [CI run 37921782620](https://github.com/tough723/music-holo/actions/runs/37921782620) 通过。 |
| **阶段 4（网页端，本轮已验收）** | 本地音乐授权句柄、导入式罗马音、自有演示音频缓存 | 不加 Electron；句柄和缓存都在浏览器本机；罗马音沿用歌词保存边界 | 刷新不自动恢复本地队列；在线播放保持原 URL，缓存只在加载失败时回退；罗马音默认隐藏，避免改变译文显示。不抓第三方音频或歌词，不做逐字歌词、托盘、全局快捷键或本机开放 API。后端验证、Compose smoke 与 25 项生产构建 Playwright 已于 [CI run 37926927032](https://github.com/tough723/music-holo/actions/runs/37926927032) 通过。 |

## 不实现或替代的边界

- 不复制 LX Music 源代码、界面资产、品牌标识或未授权音源；此矩阵只记录公开能力和交互观察。
- 不执行用户导入脚本于主页面/服务端，不绕过浏览器 CORS，不做通用代理，不把用户 Cookie/登录令牌交给自定义源。
- 不提供系统级托盘/全局快捷键/桌面置顶浮窗/本机开放 API 的假 Web 版本；浏览器有对应能力时用 Media Session、页面内快捷键等安全替代。
- 不下载、缓存、转码或分发未经 Music Holo 授权的歌曲、歌词、封面。自有演示音频只在用户明确保存后进入本机 IndexedDB；本地选择的媒体仍只在用户浏览器中处理。
- 不因“功能清单全量”就默认上线社区/追踪埋点；涉及隐私、治理、授权或长期服务维护的功能先写清验收边界再进入对应阶段。
