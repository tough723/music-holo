## 产品能力矩阵

| 能力域 | LX Music 公开能力 | Music Holo 当前对照 | 判定与处理 |
| --- | --- | --- | --- |
| 搜索与发现 | 多来源搜索、排行榜/歌单、歌曲快速换源 | 有曲库统一搜索（歌曲/歌手/公开歌单/原文与译文歌词）、排行榜、每日推荐、专辑聚合、相似歌曲电台；自定义源只负责按曲目解析 | **已有且体验方向不同**。LX 协议没有通用源侧搜索动作，Music Holo 不伪造该协议能力，不把自定义源搜索混进全局结果。 |
| 播放与队列 | 顺序/随机等播放模式、临时“稍后播放”、列表播放、队列历史/整理、快捷控制 | 已有顺序/循环/单曲循环/随机、播放全部、持久队列、睡眠定时、Media Session、键盘控制；全站歌曲行支持“下一首播放”，队列支持手动上/下移并保存曲库队列顺序 | **阶段 1 已实现并验收**。用户指定下一首优先消费一次；重复选择移动队列项而不重复加入，排序时保持当前曲目。生产构建浏览器旅程 CI run 37903076251 通过；未新增后端/API。 |
| 歌单与列表操作 | 我的列表、来源歌单、整单播放、稍后播放、多选、拖动排序、导入/导出与文本/CSV 备份 | 有账号歌单 CRUD、批量增删曲目、整单播放/加队列、公开分享、短评审核；阶段 2 新增账号歌单 JSON 备份/恢复预览 | **阶段 2 已实现，待 CI 验收**。仅导出当前账号拥有的歌单；白名单字段与大小/版本校验；导入预览、曲目匹配/歧义选择、缺失跳过；只新建副本、同名改名，默认私密、公开需逐项明确选择。凭据、歌词、音频 URL 和脚本均不导入。跨页多选不在本批范围。 |
| 本地音乐 | 本地歌曲列表、文件元数据/标签支持、添加到本机列表 | 可多选本地音频在浏览器临时播放，不上传、不写服务端历史；刷新后需重新选择文件，尚无持久句柄/标签库 | **部分覆盖，按 Web 能力优化**。后续仅在浏览器支持并经用户授权时探索持久文件句柄；拒绝静默扫描本机目录。 |
| 下载与离线 | 有下载任务队列、暂停/继续、质量/文件名/歌词标签等选项 | 没有第三方音源下载；浏览器也不应绕开版权、CORS 或站点策略 | **不照搬下载器**。仅当 Music Holo 自有/获授权媒体有清晰离线授权和存储策略时再评估；不抓取、缓存或导出未授权音频。 |
| 歌词与播放器展示 | LRC、译文/罗马音、桌面歌词浮窗与多项歌词外观设置 | 原文/译文双语 LRC、歌词上传/导出、按时间同步和沉浸式 3D 歌词；没有独立罗马音字段、桌面悬浮窗或逐字歌词协议 | **核心同步已覆盖且有原创表现**。罗马音/逐字歌词需清晰的数据格式与用户导入来源；不抓取未授权歌词、不把浏览器模拟成桌面置顶窗。 |
| 自定义源 | 用户管理源脚本；源可声明平台/音质并按协议解析音频/歌词/封面 | 有本机源库、导入/筛选/排序/备份、隔离 Worker 检测、用户逐次选源/音质并解析曲库歌曲；HTTPS/CORS、会话域名授权、匿名媒体加载 | **Web 安全适配版已覆盖关键链路**。保持隔离、不携带 Cookie/登录令牌；不绕过 CORS、不加通用代理；源搜索不属于公开通用协议动作。 |
| 同步与备份 | 桌面/移动数据同步服务；分项或全量备份/导入，另有文本/CSV 歌单导出 | 账号服务端保存收藏、歌单、播放历史/列表；浏览器有设置和自定义源的独立本机备份；阶段 2 为账号歌单提供版本化 JSON 便携备份 | **歌单迁移路径已实现，待 CI 验收**。备份只含歌单描述和曲库引用，不含账号秘密或媒体内容；其他账号数据不随本批备份。 |
| 个性化控制 | “不喜欢的歌曲/歌手”规则，切歌时自动跳过，可手动播放 | 有收藏、最近播放、推荐画像，无独立用户屏蔽规则 | **明确差距**。后续可做账号隔离的“不喜欢”规则，影响自动推荐/切歌而不删除歌曲；需先定义对手动播放、相似歌曲及管理员视图的边界。 |
| 设置与搜索偏好 | 音源、网络代理、音频设备、播放/歌词、列表、下载、搜索、快捷键、同步、备份等设置 | 有主题/动效/玻璃、播放模式/音量、搜索隐私、本机备份、账号资料与安全、自定义源设置 | **功能域已覆盖主要 Web 需求**。代理、系统音频设备和下载路径属于桌面/浏览器受限项，不为了形式对齐添加脆弱开关。 |
| 桌面/系统集成 | 全局快捷键、托盘、开机启动、始终置顶的独立桌面歌词窗、桌面开放 HTTP API、Scheme 启动参数 | 浏览器内键盘操作、Media Session 系统媒体控件、响应式窄屏播放器 | **不做 Electron 伪实现**。改用浏览器安全能力；宿主全局输入、托盘、任意本机 HTTP 控制面不进入 Web 版本。 |
| 社交/协作 | LX 核心不是实时协作社区 | 有歌曲/公开歌单短评、举报审核、公开歌单分享；没有协作编辑/同步听 | **当前已有 MVP**。协作歌单/一起听需要真实需求、内容治理与实时服务验算，不列入阶段 1。 |

## 分阶段实现顺序

排序依据是“用户任务覆盖 × 实现/维护负担 × 版权与安全风险”的相对判断，不是增长预测。当前没有真实用户使用基线，不承诺转化或留存提升；后续用真实测试与反馈重新排序。

| 顺序 | 工作包 | 优先级 / 规模 | 验收边界 |
| --- | --- | --- | --- |
| **阶段 1（本轮，已验收）** | 播放队列“下一首播放”与手动排序 | 高优先级，前端小改动；无需 SQL、服务端接口或第三方服务 | 在歌曲列表可把曲目排到正在播放曲目之后；重复选择移动已入队曲目而不是制造重复；队列上/下移后播放中的曲目保持不变；刷新后合法曲库队列顺序仍保存；本地 Blob/自定义源签名 URL 仍不进入持久化队列。Store 测试通过，生产构建 Playwright 于 [CI run 37903076251](https://github.com/tough723/music-holo/actions/runs/37903076251) 通过。 |
| **阶段 2（本批实现中，待 CI 验收）** | 当前账号歌单 JSON 备份/恢复；跨页多选延期 | 中优先级；沿用现有歌单/曲库 API，新增专用前后端服务、DTO/VO、校验和测试；不加表、不做跨页选择；本轮未记录实际工时，不能据此声称具体人日 | 登录账号只能导出自己的歌单；2 MB/版本/白名单字段与数量校验；导入先预览，重名自动改名且只新建；默认私密，只有用户逐项勾选才公开；缺失歌曲显示并跳过，多个候选需人工选择；凭据、歌词、音频 URL、脚本不导入。CI 需通过后端验证、API smoke 与 Playwright 旅程。 |
| 阶段 3 | “不喜欢”歌曲/歌手规则 | 中优先级，需 API/数据迁移与切歌规则 | 账号隔离；可撤销；自动下一首/推荐遵循规则；用户仍可显式手动播放；匿名行为不写入他人数据。 |
| 阶段 4（条件项） | 本地音乐持久句柄、罗马音/逐字歌词、授权离线能力 | 依浏览器支持、数据格式、许可和维护成本决定 | 先验证浏览器兼容及用户授权；若不能可靠还原权限或无法确认媒体授权则不实现。 |

## 不实现或替代的边界

- 不复制 LX Music 源代码、界面资产、品牌标识或未授权音源；此矩阵只记录公开能力和交互观察。
- 不执行用户导入脚本于主页面/服务端，不绕过浏览器 CORS，不做通用代理，不把用户 Cookie/登录令牌交给自定义源。
- 不提供系统级托盘/全局快捷键/桌面置顶浮窗/本机开放 API 的假 Web 版本；浏览器有对应能力时用 Media Session、页面内快捷键等安全替代。
- 不下载、缓存、转码或分发未经 Music Holo 授权的歌曲、歌词、封面；本地选择的媒体仍只在用户浏览器中处理。
- 不因“功能清单全量”就默认上线社区/追踪埋点；涉及隐私、治理、授权或长期服务维护的功能先写清验收边界再进入对应阶段。
