# 实时在线发现平台子标签实施计划

## 目标
将搜索页的在线结果从单平台下拉框改为平台子标签，保持本站曲库结果不变，并实现按需加载、平台级缓存、错误隔离和统一播放/队列入口。

## 范围
- `music-holo-web/src/views/Search.vue`
- 搜索页相关测试
- 不修改平台适配器和 `onlineTrackService`，因为四个平台搜索能力已经存在。
- 本轮同步修复排行榜已发现的竞态/恢复问题，并更新过时的排行榜 E2E 断言。

## 任务
1. 先补平台状态纯函数/测试，定义平台列表、初始化状态、重置状态。
2. 在 Search.vue 引入四个平台子标签、独立缓存和按需加载；增加查询代次保护，避免旧查询覆盖新结果。
3. 在 Charts.vue 增加在线榜单/曲目请求代次、加载状态、错误恢复和无数据清理；补充可访问状态。
4. 更新排行榜真实栈 E2E，使本地榜测试显式切换“本站播放榜”，新增在线榜单回归覆盖。
5. 运行 Web 单测、构建和真实栈浏览器验证，提交并推送。

## 验收
- 搜索页保留本站歌曲/歌手/歌单标签。
- 在线平台标签包含 wy/kw/kg/mg，默认只自动加载 wy，切换其他平台才请求。
- 已加载平台切回不重复请求；单个平台错误不清除其他平台缓存。
- 查询变化清空所有在线缓存并回到 wy。
- 排行榜快速切换平台/榜单时旧响应不能覆盖当前状态；失败后切换榜单可恢复。
- 真实运行栈加载实时榜单和曲目，所有 Web 测试与构建通过。
