# 音乐平台能力盘点与本项目补齐计划

> 桌面扩展说明：现新增 Electron 自定义源宿主与受控本机网络桥，状态与边界见 [桌面客户端说明](desktop-client.md)。以下历史审计主要针对网页版，原 CORS 边界仍适用于网页；新增桌面访客链路和 Linux 目录打包已通过 [CI](https://github.com/tough723/music-holo/actions/runs/37965363398)，音源服务为模拟数据，真实第三方接口仍待验收。

> 目标是提炼主流产品的通用交互能力，形成原创的 Music Holo 体验；不复制竞品 Logo、专有文案、版权音频或商业素材。

## 市场能力观察

| 方向 | 成熟产品常见做法 | 对本项目的启发 |
| --- | --- | --- |
| 个性化发现 | Spotify 提供 Spotify Mixes、Discover Weekly、Release Radar、Daylist 等面向不同时间与偏好的歌单；Apple Music 根据聆听历史推荐艺人与专辑。 | 从收藏、最近播放、曲风分类、歌手偏好生成可解释的“为你推荐”，冷启动回落到热歌榜。 |
| 搜索 | YouTube Music 支持按歌词找歌；成熟搜索通常横跨歌曲、艺人、歌单等内容类型。 | 做统一搜索入口，原歌词/译文、歌名、专辑、歌手、歌单均可成为入口。 |
| 连续收听 | 个性化混音、自动续播、最近播放与年度回顾降低“下一首听什么”的成本。 | 最近播放已按用户保存，支持分页、单条删除与清空；本轮在首页增加「继续收听」快捷入口，点选最近曲目即可恢复播放，不额外复制一份历史数据。 |
| 社交与 UGC | Spotify 有好友分享、协作歌单与 Jam；网易云强调 UGC 歌单、乐评、一起听及社区。 | 已有用户歌单、公开分享链接，以及歌曲/歌单短评 MVP（分页、发布、点赞、举报、管理员审核）；关注歌手、协同编辑与一起听仍属后续独立阶段。 |
| 歌词与演出 | Apple Music 强调实时歌词、翻译/发音；YouTube Music 用 Samples、艺人电台和视频帮助发现歌曲。 | 现有 LRC 同步播放已具基础；本轮增加基于歌曲/歌手/分类的相似歌曲电台 MVP 和可选译文 LRC；发音/罗马音与多语言歌词索引仍属后续。 |

## 与当前项目对照

### 已有

- 歌曲/歌手/歌单/分类浏览，关键字筛选与分页。
- 全息主题、收藏、个人播放队列、原歌词 / 可选译文的双语 LRC 同步显示、歌单 CRUD。
- 管理后台、文件上传下载、歌手 CSV 导入导出。
- 播放器适配窄屏，并支持空格播放/暂停、方向键跳转、Shift + 方向键切歌、L 打开歌词、Q 打开队列。

### 本轮补齐

1. **全站 3D 视觉贯穿**：统一空间环境层（透视网格、轨道光环、体积光与粒子），将景深玻璃、轻量卡片倾斜、播放器投影与动态主题覆盖到登录、内容、管理和播放流程，并尊重系统减少动态效果设置。
2. **统一搜索**：跨歌曲（标题/专辑/原歌词/译文/歌手）、歌手、公开歌单检索；搜索入口支持 `Ctrl/⌘ + K`。
3. **最近播放**：后端按用户保存歌曲与最后播放时间/次数，可分页、移除单项、清空；播放量接口对匿名访问开放，但只有登录用户写个人历史。
4. **个性化推荐**：按用户近期播放与收藏的歌手/分类做透明的内容匹配；新用户与匿名用户回落到热歌榜。这是可解释的冷启动基线，不宣称为机器学习算法。
5. **排行榜**：综合榜与分类榜，基于已有播放量排序。
6. **隐私补强**：私密歌单详情与曲目必须由创建者或管理员访问；匿名用户“只看我的”返回空结果。
7. **每日推荐入口**：新增独立的每日推荐页，复用用户近期收听/收藏画像，支持按曲风筛选、批量播放和加入队列；匿名访问回落到热歌推荐。
8. **睡眠定时**：播放器提供 15/30/45/60 分钟后暂停，或播完当前曲目后停止；切歌会取消“播完当前曲目”模式，跨路由保留。倒计时使用本机时钟，不是操作系统闹钟；刷新会重置，浏览器/系统挂起时可能延迟触发。
9. **公开歌单一键分享**：公开歌单详情增加原生系统分享与复制链接回退；私密歌单不显示分享入口，URL 由当前站点路由生成，不依赖第三方服务。
10. **本地音频与浮动播放器（本轮）**：队列支持多选本地音频文件，临时 Blob URL 只在浏览器内播放、不上传服务端，也不写入远程播放历史；固定播放器和歌词层 Teleport 到 body，脱离 3D / overflow 祖先布局，滚动页面时保持悬浮。刷新需重新导入；浏览器编解码支持因格式/平台而异。
11. **歌曲 / 公开歌单短评 MVP（本轮）**：游客可分页读取公开短评，登录用户可发布（最多 500 字、每分钟 3 条）、点赞、举报，作者只能删除自己的内容；私密歌单短评沿用所有者/管理员访问权限。管理员可驳回举报、隐藏/恢复短评；隐藏时同一短评的待处理举报一并结案，审核说明仅作者与管理员可见。短评与管理员队列加载失败会明确提示并提供重试，避免把服务不可用误判为空列表；快速切换对象/筛选时忽略过期响应。Mock、API 权限测试与 Playwright 端到端旅程同步覆盖；UGC 即时公开，真实试运行前须明确举报队列责任人。
12. **首页继续收听（本轮）**：已登录用户首页读取自己的最近播放记录，展示少量一键续播卡片，并可跳转完整历史页；游客不请求私人历史。首页各个 discovery API 改为独立容错，单个推荐模块暂时失败不会清空其他已加载内容，显示明确错误和重试入口。复用现有历史接口，不增加新表或埋点。
13. **每日推荐失败态修复（本轮）**：推荐接口暂时失败时，不再把“无法连接”伪装成“当前没有推荐”，也不清空之前已加载的歌曲；页面显示可重试提示。分类筛选或收藏状态接口单独失败时，仍保留可用的推荐列表。未增加新接口、数据库或分析埋点。
14. **HRTF 虚拟空间音效（本轮）**：播放器新增耳机空间音效开关，对本地 Blob / 同源立体声音源做左右虚拟声源 HRTF 混合，保留原声路径并能随时切回；跨域音源继续走原生播放器、不接入 Web Audio。它是可选的虚拟声场处理，不是多声道母带或头部追踪，不宣称为真 Dolby Atmos。未增加服务端或存储依赖。
15. **系统媒体控件接入（本轮）**：通过浏览器 Media Session API 同步曲名、歌手、封面和进度，并响应系统/耳机的播放、暂停、上一首、下一首及 seek 操作。仅在浏览器支持时启用；不增加第三方脚本、音源接口或后端依赖。
16. **导航分组与响应式布局（本轮）**：将桌面侧栏和窄屏抽屉改为共用 `AppNavigation`，按发现、曲库、我的音乐、管理、偏好分组；歌手/歌单/专辑详情页高亮所属入口。桌面侧栏可折叠并把选择保存在本机，中等窗口自动收窄；宽度不超过 600px 时隐藏侧栏，由顶部按钮打开同一导航抽屉，选路由后自动关闭。游客菜单显示登录/注册，隐藏退出登录。前端重构，不改变服务端路由/权限。
17. **专辑库与详情（本轮）**：从已上架歌曲按专辑名与歌手聚合分页，不新增专辑主表；支持按专辑/歌手搜索、曲目列表、播放整张专辑和加入队列。歌曲列表中的专辑名可直接进入详情；歌词字段不会随专辑曲目接口返回。
18. **相似歌曲电台（本轮）**：从播放器或曲目上下文进入，按相同歌手/分类排序、排除起点曲目，候选不足时用热度曲目补齐；可整组播放、单曲播放或加入队列。匿名用户也可使用，不接外部推荐服务或音源脚本。
19. **设置中心补强（本轮）**：沿用 Music Holo 现有设置能力，新增设置页签本机记忆、主题同步成功/失败状态与重试；个人资料增加邮箱/手机号/昵称校验、头像格式和 5 MB 限制，密码修改使用表单校验并明确成功后退出。玻璃透明度仍仅本机保存。
20. **自定义源导入管理、隔离检测与按曲目解析播放（本轮）**：本机源库支持文件或 HTTPS URL 导入 `.js/.mjs`，读取 LX 常见头部元数据，筛选、重命名、排序、查看、导出/恢复备份和删除；按当前账号分隔保存在浏览器本机，单个文件 128 KB、最多 24 个。导入本身不执行脚本；歌曲列表仅在本机已有源时显示「使用自定义源播放」。用户逐次选择脚本、平台与音质并确认初始化后，隔离 Worker 按 LX 兼容协议调用 `musicUrl`，传入当前曲库歌曲的公开元数据；还可临时补充 `songmid` 等平台 ID，敏感凭据字段拒绝。声明 `lyric`/`pic` 时按需调用，媒体加载另需确认来源；同源媒体 URL 会拒绝，避免播放器请求携带 Music Holo 站点凭据。已选音源失败时可关闭对话框、改用曲库默认播放。音源 URL 仍由浏览器匿名 CORS 加载；音源请求按会话逐域名授权，只允许 HTTPS、无 Cookie/登录态、CORS GET/POST/HEAD，超时/响应体积/并发受限；用户同意的域名授权在本次运行后失效。音源曲目和签名 URL 只在内存队列/当前浏览器会话，不写服务端历史或持久播放队列；自定义源封面不传给系统 Media Session。LX 自定义源协议不定义通用 `search` 动作，因此全局搜索仍仅搜索 Music Holo 曲库；不绕过 CORS，不代表第三方源或曲库已获授权。常见本机地址会拦截，但浏览器无法可靠识别全部 DNS 重绑定风险，仍须只运行可信且获授权脚本。
21. **双语 LRC 歌词（本轮）**：每首曲目可独立保存原文与可选译文 LRC；管理员歌曲表单支持文本编辑、`.lrc/.txt` 上传并保存。歌词解析 API 同时返回两组时间行，播放器按最近时间标签配对、默认展示译文并提供开关；全局搜索可命中译文，列表接口不携带歌词正文。旧客户端省略译文字段不会覆盖现有值，显式提交空串用于清除。新建 SQL、可重复执行的 MySQL 8.0 增量迁移、Mock、API 测试和管理员上传到播放器切换的浏览器旅程同步覆盖；不自动翻译、不调用未授权歌词源。
22. **LX 队列操作补齐（阶段 1，已验收）**：全站歌曲行可把歌曲排到当前曲目之后；若目标已在队列则移动而不重复。播放队列提供无障碍上/下移，保持当前曲目不变并保存曲库队列顺序；用户指定的“下一首”优先于随机/单曲模式一次。Blob 本地音频和自定义源签名 URL 仍不持久化。Store 覆盖重复选择、越界、随机优先级和隐私边界；生产构建 Playwright 浏览器旅程已于 CI run 37903076251 通过。
23. **账号歌单 JSON 备份/恢复（阶段 2，已验收）**：只导出当前账号自己拥有的歌单；采用版本化白名单格式和 2 MB/数量/字段上限。导入先展示匹配预览，不覆盖现有数据；同名生成建议新名称，执行时仅在并发占名时追加后缀。新歌单默认私密，只有用户明确勾选才公开；未匹配歌曲可见并跳过，歧义候选由用户选择。不会导入凭据、歌词、音频 URL、封面或可执行脚本；不运行导入内容。导出生成后由用户点击真实链接保存。本批不包含跨页多选。前后端 Mock/格式/服务测试、生产浏览器旅程和 CI API smoke 已于 [CI run 37910475171](https://github.com/tough723/music-holo/actions/runs/37910475171) 通过。

24. **播放器控制面补齐（本轮）**：进度条支持指针拖拽/悬停时间预览/缓冲范围显示与完整键盘操作（← → ±5 秒、↑ ↓ ±10 秒或音量、Home/End、PageUp/PageDown ±30 秒），拖动结束才真正 seek；新增 0.5×–2× 倍速（只接受固定档位并持久化）、静音（保留原音量，拖动音量自动解除静音）与断点续播（每 5 秒记录一次进度，同一首歌下次进入时继续；短于 5 秒或距结尾不足 15 秒则从头开始；本地 blob 与自定义源签名地址不记录）；缓冲/等待有独立指示，加载失败给出手动重试入口，浏览器拦截自动播放时明确提示而不是静默暂停。当前曲目可在播放器上直接下载或标记不喜欢；播放队列新增关键词搜索、随机打乱（当前曲目保持在队首）、移除重复曲目与总时长，并支持打开时滚动定位到当前曲目。倍速只改变播放速度，不做变调处理；断点续播依赖 localStorage，换设备/清理站点数据后失效。Store 单测覆盖档位收敛、静音恢复、续播边界与队列打乱/去重，另用 jsdom 挂载真实组件覆盖静音、倍速、进度 aria 与队列过滤/去重交互。
25. **歌词舞台与桌面歌词窗（本轮）**：歌词显示偏好（译文/罗马音/逐字/沉浸/字号/时间校准）从组件内部状态迁移到播放器 store 并持久化，关闭面板、刷新页面后仍然保留；新增 ±0.5 秒的时间校准（上限 ±5 秒，正值＝歌词提前），高亮与逐字进度按校准后的时间轴判定，点击歌词行会换算回真实播放时间，[ / ] 可直接微调，歌词为空时提供「重新加载歌词」。歌词行号随字号档位缩放。播放队列条目改为 listbox/option 语义，支持拖拽排序（搜索过滤时禁用）与键盘操作（回车播放、Delete 移除、Alt + ↑/↓ 移动且焦点跟随）。桌面歌词窗与主窗口共用同一套偏好：推送状态新增白名单字段 `lyricView`（译文/字号/校准），歌词窗的译文开关本地持久化，并支持空格切播放、←/→ 切歌、T 译文、[ / ] 校准，校准请求通过 `lyricOffset` 命令转发回主窗口的播放器 store，歌词窗自己不保存播放数据。桌面端为 `sanitizeLyricView` 增加了单测（越界夹取、非 https 封面与非法歌词数组丢弃），web 端新增 8 条歌词面板测试与 2 条队列交互测试。
26. **空间音效的恢复与记忆（本轮）**：`createSpatialAudioGraph` 新增 `state` 与 `resume()`——浏览器在后台标签页、系统休眠或长时间空闲后会 suspend 掉 AudioContext，此时媒体元素仍在播放但经 Web Audio 的声音会完全静音，播放器现在会在开始播放、以及页面回到前台（`visibilitychange`）时重新 resume。空间音效开关作为输出偏好持久化到 `spatialPreferred`：在用户手势（pointerdown/keydown 后 1.5 秒内）触发播放时自动套用；音源不支持或浏览器拒绝时不改写偏好，只关掉本次会话，换一首同源的歌还会再试，同一首歌只尝试一次。手动关闭会清掉偏好。单测覆盖 `resume()` 的挂起/已运行/关闭/被拒四种状态、偏好的持久化与“失败不清除偏好、回退原声继续播放”的行为。
27. **离线副本与播放衔接（本轮）**：网络音频不可用时会回退到本机保存的演示副本（blob URL）。删除副本会 revoke 该 blob，若此刻正在用它播放，播放器会在删除后把音源切回在线地址、保持进度并继续播放，同时给出提示；删除的不是当前曲目副本时完全不动正在播放的音源。删除失败也改为提示而不是抛出未处理的 Promise 异常。新增 2 条 jsdom 测试（mock 掉 IndexedDB 缓存模块）覆盖这两种路径。
28. **播放器形态：标准 / 迷你 / 沉浸（本轮）**：`playerViewMode` 持久化到 `mh_player`，点播放条右侧的形态按钮或按 V 键在 标准 → 迷你 → 沉浸 之间循环。迷你与沉浸形态通过 `<html>` 上的 `mh-player-mini` 类把全局 `--player-h` 从 88px 收到 56px（窄屏 108→64px），页面留白同步收窄；次要控件（下载/不喜欢/换源/电台/音量滑杆/倍速/空间音效/快捷键说明/睡眠定时）由 CSS 隐藏但节点保留，避免打断正在进行的交互。沉浸形态自动打开歌词舞台的 immersive 模式；在歌词舞台里按 Esc 退出时，播放器形态通过 `lyricView.immersive` 的 watcher 同步回到标准，不会留下互相矛盾的状态。单测覆盖循环顺序与非法值回落、持久化、按钮 aria 与形态类名、V 键切换、以及“歌词舞台退出沉浸 → 形态回退”。此外新增 [`docs/player-optimization-proposal.md`](player-optimization-proposal.md)：把已落地能力固化为基线，并按 收益/风险 排出均衡器、迷你贴边、Now Playing 页、播放模式扩展、队列批量操作、交叉淡入等后续项，每项给出问题/方案/影响面/风险/验收与降级矩阵。

LX Music 的全量公开能力矩阵见 [`lx-music-feature-parity.md`](lx-music-feature-parity.md)：区分已覆盖、待补齐、Web/安全适配及不实现的桌面专属能力。

## 权益与安全边界

- 版权曲库、MV、离线缓存和高解析音源需要授权与实际媒体服务，本项目不抓取第三方平台数据或素材。
- 现有音频为本项目生成的演示音频；生产环境应仅使用已获授权的文件，并配置版权、删除与投诉流程。
- 个性化历史与收藏均按用户隔离；提供删除/清空入口，不能通过猜测 ID 读取私密歌单。
- LX Music Desktop 虽标注 Apache 2.0，但同时附有非商业等补充条款；`pdone/lx-music-source` 未声明明确许可证，野花脚本高度混淆。本项目不复制这两个源的代码，也未运行或导入其脚本；隔离兼容检测仅用于用户自行审阅并明确同意的脚本，且不代理音频链接、不绕过 CORS。
